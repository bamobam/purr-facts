# Offline ETL into a static dataset, no runtime upload API

Data (Open Pet Food Facts + openFDA recalls + the manually-curated product set) is merged and filtered once via an offline ETL script into a single static dataset file, baked into the app/Docker image and loaded into memory at server startup. We rejected keeping a runtime "upload a dataset" API like the original course project's `addDataset`/zip-upload pattern, because this app serves one fixed public dataset rather than acting as a multi-tenant grading system — that API surface would be unused complexity. This also intentionally distances the new app's API shape from the original assignment's most distinctive endpoint, which matters given [ADR 0001](./0001-clean-room-reimplementation.md)'s clean-room stance. A reader familiar with the original project should expect this difference rather than assume it was missed.

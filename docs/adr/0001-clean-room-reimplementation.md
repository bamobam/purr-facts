# Clean-room reimplementation of the query engine

This project repurposes the design of a CPSC 310 course assignment (a filter/group/aggregate query engine) into a new public portfolio piece, but CPSC 310's academic-integrity policy on publishing derived/repurposed course code has not yet been confirmed (the user is checking separately). Until that's resolved, we treat the original project as an architectural reference only — no copied files, no reused test fixtures or specs, and new class/type names fit to the cat-food domain rather than the original's naming (e.g. not `InsightFacade` verbatim). This is deliberately more conservative than necessary if the policy turns out to be permissive, but it's a one-way door once code is public: reusing too much and being wrong can't be undone, while reusing too little just costs some rewrite time we can loosen later.
